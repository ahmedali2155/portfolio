# Ahmed Ali — Portfolio

A modern, responsive, and production-ready personal portfolio showcasing my experience as an AI & Software Engineer. Built with React, TypeScript, Vite, and Tailwind CSS, the website highlights my internships, projects, technical skills, education, and professional journey.

## Live Demo

**Portfolio:** https://YOUR-PORTFOLIO.vercel.app

## Features

- Modern responsive UI
- Dark theme with professional design system
- Project showcase with detailed case studies
- Internship & experience timeline
- Skills organized by category
- Education & certifications
- Resume download
- Contact form
- SEO optimized
- Accessible and keyboard friendly
- Fast performance with Vite

# Installation

Clone the repository

```bash
git clone https://github.com/ahmedali2155/portfolio.git
```

Move into the project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open

```
http://localhost:5173
```

---

# Production Build

Build the application

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```

# Customization

The portfolio is completely data-driven.

Simply update the files inside:

```
src/data/
```

without modifying any UI components.

| Update | File |
|---------|------|
| Personal information | `profile.ts` |
| Projects | `projects.ts` |
| Internships | `internships.ts` |
| Skills | `skills.ts` |
| Education | `education.ts` |

# Deployment

The project is optimized for deployment on **Vercel**.

1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Framework Preset: **Vite**
4. Deploy.

No additional configuration is required.
